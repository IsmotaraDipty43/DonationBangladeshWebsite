# **Donate Bangladesh**

## **Description**
**Donate Bangladesh** is a donation app focused on providing aid to flood-affected people in various districts of Bangladesh, as well as supporting humankind donations.

## **Key Features**
- **Blog Button**: Redirects users to the blog page when clicked.
- **Back Button**: Available on the blog page to navigate back to the homepage.
- **Account Balance**: Displays the current balance, and after donating a specific amount, the balance is updated, reflecting the deducted amount.
- **District Donations**: Users can donate a specified amount of money to different districts affected by floods. The donation will show a modal thanking the user and indicating the district.
- **Transaction History**: A history button is available to display the transaction history of donations.

## **Technology Stack**
- **Frontend**: **JavaScript**, **Tailwind CSS**, **HTML**
- **Mobile Responsive**: Ensures a smooth user experience on mobile devices.
